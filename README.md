# Tami Bedford Website

Premium music academy and creative studio website for Tami Bedford Sessions.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Lucide React icons

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Check

```bash
npm run lint
npm run build
npm run start
```

## Routes

- `/`
- `/sessions`
- `/sessions/piano`
- `/sessions/organ`
- `/sessions/production`
- `/services`
- `/work`
- `/about`
- `/apply`
